# GitHub 健身动作库 & 运动指导开源项目调研报告

> 调研时间：2026-11-05 | 数据来源：GitHub Topic、第三方统计站、技术博客交叉验证

---

## 一、全景概览

GitHub 上的健身开源生态可以分为 **四大赛道**：

| 赛道 | 定位 | 代表项目 |
|------|------|----------|
| **动作数据集** | 纯数据层，给开发者喂料 | exercises-dataset、free-exercise-db |
| **完整平台** | 自托管的训练记录/计划系统 | openGym、workout-cool、wger |
| **3D 可视化 / 姿态识别** | 3D 肌肉模型、动作捕捉、AI 纠错 | FitFormLive、peak-fit |
| **商业 API** | 托管式动作数据库接口 | ExerciseDB (AscendAPI) |

## 二、动作数据集（最火赛道）

### 1. hasaneyldrm/exercises-dataset ⭐ 23.5K — 当之无愧的顶流

- **内容**：1,324 个健身动作，每个含动画 GIF、180×180 缩略图、目标肌群/器械元数据、分步说明
- **语言**：支持 10 种语言（英/西/意/土/俄/**中**/印地/波兰/韩/法）
- **亮点**：
  - 纯前端 `index.html` 离线浏览器，实时搜索 + 肌群/器械筛选
  - `setup.html` 一键生成 SQL 建表语句（MySQL/PostgreSQL/SQLite/SQL Server）+ 7 种语言 API 调用示例
  - 自带 LLM 提示词，可让 AI 直接生成后端 API
- **授权**：代码 MIT；图片/GIF 版权属 Gym Visual（商用需自行核实授权）
- **背景**：是训练记录应用 LogPress 的数据层，曾单日涨 942 星登顶 GitHub 热榜

### 2. yuhonas/free-exercise-db ⭐ 2.1K — 公有领域干净数据

- **内容**：876 个动作（实测解析数），纯 JSON + 静态图片
- **亮点**：**Unlicense（公有领域）**，文本数据无任何授权顾虑；自带可搜索前端
- **适合**：需要干净、可自由分发的结构化动作数据的项目
- **注意**：图片授权仍有争议，官方已移除 imageUrl 字段

### 3. ExerciseDB/exercisedb-api ⭐ 739 — 商业 API（托管）

- **内容**：11,000+ 动作、15,000+ 视频、5,000+ GIF、男女双版本动画
- **模式**：RapidAPI 订阅制，V1 免费 1,500 动作（180p GIF），V2 付费解锁 MP4
- **注意**：**不可自托管**，禁止缓存/再分发，本质是 SaaS

## 三、完整平台（自托管训练系统）

### 1. DuarteSantos8/openGym ⭐ 19.1K — 增速最猛

- **定位**：自托管健身追踪器，"数据归你所有"
- **亮点**：
  - 内置 1,324 动作库（与 exercises-dataset 同源），带动画演示
  - 周计划编排（超级组/热身组/递减组）、引导式训练记录、PR 检测
  - 肌群疲劳/欠练分析、体重追踪、估算 1RM
  - Passkey 登录（Face ID/Touch ID）、PWA、离线可用、CRDT 多端同步
  - 支持从 FitNotes/Strong/Hevy 导入历史数据
  - Docker Compose 一行部署
- **授权**：AGPL-3.0
- **增速**：2026 年 10 月单周 +3,000 star，单日最高 +243

### 2. Snouzy/workout-cool ⭐ 8.7K — 现代全栈

- **定位**：开源健身指导平台（训练计划 + 进度追踪 + 动作库）
- **技术栈**：Next.js + TypeScript + PostgreSQL + Prisma + shadcn/ui
- **亮点**：MIT 授权、Vercel OSS 计划支持、feature-sliced 设计、类型安全
- **背景**：作者是原 workout.lol 的核心贡献者，项目被出售后弃坑，遂重写

### 3. wger-project/wger ⭐ 7.2K — 老牌全功能

- **定位**：自托管健身/营养/体重管理（Django）
- **亮点**：训练 + 饮食 + 体重 + 身体测量全覆盖，REST API 完善，社区多语言（Weblate）
- **适合**：需要饮食管理 + 想接 AI Agent 读写训练数据的场景
- **授权**：代码 AGPL-3.0，数据/图片按条目单独授权（CC 系列）

## 四、3D 可视化 / 姿态识别（与你截图最相关）

### 1. OliverLee9292/FitFormLive — 浏览器端 AI 私教

- **能力**：实时姿态估计（MoveNet/BlazePose）+ **Three.js 3D 虚拟人镜像** + TTS 语音指导
- **亮点**：纯浏览器端运行、无需后端推理、零视频上传、支持弯举/深蹲/箭步蹲/俯卧撑/肩推
- **技术**：BlazePose 33 关键点 → GLTF 骨骼重定向 → Three.js 渲染

### 2. sscodes/peak-fit — 3D 肌肉高亮

- **能力**：选择动作 → 3D 人体模型实时高亮目标肌群（主动肌红色/辅助肌橙色）
- **技术**：React + Three.js/R3F + 自定义 Blender 分割 GLB 模型（29 肌群）

### 3. SheepDoctor/WorkOut — 姿态检测 + 3D 肌肉

- **能力**：MediaPipe 实时摄像头姿态检测 + AI 动作纠错 + 3D 肌肉群可视化
- **技术**：Django + Vue 3 + Three.js + MediaPipe

## 五、选型建议

| 你的需求 | 推荐 |
|----------|------|
| **只要动作数据，快速接入项目** | `exercises-dataset`（量大、多语言、脚手架全） |
| **数据要完全无版权顾虑** | `free-exercise-db`（Unlicense） |
| **要一个能直接用的训练记录 App** | `openGym`（功能最全、社区最活跃） |
| **要训练+饮食+API 全家桶** | `wger` |
| **要 3D 动作演示/肌肉可视化** | `FitFormLive` + `peak-fit` 组合参考 |
| **要中英双语动作库** | `gym-exercise-guide`（873 动作/1746 图） |
| **需要高质量动画/视频素材** | ExerciseDB V2（付费 API，素材最丰富） |

## 六、关键洞察

1. **数据集赛道一家独大**：exercises-dataset 以 23.5K 星遥遥领先，几乎成了行业事实标准，openGym 也直接复用它的数据
2. **"数据主权"是核心叙事**：openGym、wger、workout-cool 全部主打自托管/无订阅/数据归用户，直击 Hevy/Strong 等商业 App 的痛点
3. **3D 方向还在早期**：3D 肌肉可视化和姿态识别项目星数都不高（几百到一千多），但和 AI 结合的想象空间大——你看到的 DeepSeek Harness "Fit Studio" 就是 AI 实时生成 3D 动作演示的典型案例
4. **商用注意**：几乎所有项目的"图片/动画"素材都有独立授权（多来自 Gym Visual），与代码授权分离，商用前务必逐条核实
